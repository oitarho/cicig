UI / CONTROL_DECK

A panel without mazes

Both protocols live in one compact registry: clients, traffic, expiration, and quick actions remain visible without unnecessary navigation.

01 / ACCESS_VAULT

Everything for access

The administrator operates both VPN protocols as one system. The user only needs to import a ready-to-use configuration.

01.1

Unified registry

WireGuard and AmneziaWG clients, search, connection status, and traffic on one screen.

01.2

Issue keys

Create a client and deliver a ready .conf file or JPEG QR code without exposing internal VPN panels.

01.3

Expiration control

Extend, manually disable, or automatically revoke expired access.

01.4

Domain endpoints

Client configurations connect to your domain instead of a hard-coded IP address.

01.5

Full-system updates

Update the code and containers manually or automatically while preserving keys and data.

02 / SIGNAL_ROUTE

Clear architecture

03 / SERVER_PROFILE

Start small

Size the server by concurrent connections and real traffic, not by the total number of issued keys.

Minimum node

2vCPU
2 GBRAM
  • 20 GB SSD
  • Public IPv4 address
  • 100 Mbps or faster connection
  • Ubuntu 22.04/24.04 or Debian 12
  • TUN/TAP and amd64 architecture
Concurrent clientsServerConnection

Connection planning: concurrent clients × average client speed + 20–30% headroom. For more than 300 concurrent connections, distribute clients across independent cicig servers.

04 / DEPLOY_SEQUENCE

Three steps to a tunnel

The installer validates DNS, installs Docker, starts every service, and obtains an HTTPS certificate.

01

Prepare DNS

Create two A records pointing to the server IPv4: root @ and panel. Set Cloudflare to DNS only.

02

Run the command

Sign in to a clean server as root and start the installer.

curl …/install.sh | sudo bash
03

Issue access

Open the panel, create a client, and deliver its .conf file or QR code.
