# cicig

`cicig` — кошачья root-консоль, которая одной командой поднимает два зашифрованных тоннеля и прячет всю рутину под одной русскоязычной панелью:

- `panel.example.com:443/tcp` — единая веб-панель cicig;
- `example.com:51820/udp` — адрес WireGuard в клиентских конфигурациях;
- `example.com:443/udp` — адрес AmneziaWG в клиентских конфигурациях;
- Caddy автоматически получает и продлевает HTTPS-сертификат.

HTTP/3 отключён, потому что UDP-порт 443 используется AmneziaWG.

## Поднять ноду одной командой

Запустите на чистом сервере от пользователя с правами `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/oitarho/cicig/main/install.sh | sudo bash
```

Установщик попросит указать основной домен, например `mydomain.com`. Поддомен `panel.mydomain.com` он сформирует самостоятельно. Перед изменением сервера установщик покажет две необходимые DNS-записи типа A и будет проверять их, пока обе не начнут указывать на публичный IPv4 сервера.

Если DNS управляется через Cloudflare, для обеих записей нужно выбрать **DNS only** — серое облако. Проксирование Cloudflare не пропускает необходимый VPN-трафик UDP.

Когда DNS пройдёт фейс-контроль и кот убедится, что хвоста нет, установщик:

1. Упакует Docker и Docker Compose в рюкзак, если их ещё нет.
2. Попросит мастер-пароль от кошачьего сейфа.
3. Развернёт базу в `/opt/cicig`.
4. Спрячет секреты в защищённый `.env`.
5. Выпустит в сеть Caddy, cicig, WireGuard и AmneziaWG.

До запуска контейнеров установщик также проверяет архитектуру `amd64` и наличие `/dev/net/tun`. Если TUN/TAP отключён у VPS-провайдера, установка остановится с понятной инструкцией вместо бесконечного перезапуска AmneziaWG.

## Что умеет кошачья root-консоль

Интерфейс разделён на два компактных экрана: **«Ключи»** для ежедневной работы с клиентами и **«Узлы и патчи»** для состояния контейнеров и обновлений. Больших декоративных блоков на рабочем экране нет — кот не занимает место, пока оператор занят.

- единый сейф агентов WireGuard и AmneziaWG;
- выпуск ключа с таймером самоуничтожения и запиской в досье;
- пробив базы по имени, IP и криптографическому отпечатку;
- фильтрация по VPN, сроку и состоянию связи;
- статусы «онлайн», «недавно» и «офлайн»;
- отдельная карточка клиента с IP, ключом, трафиком и датами;
- QR-код в формате JPEG и скачивание `.conf`: кириллическое имя автоматически транслитерируется для совместимости с приложениями WireGuard;
- endpoint в скачиваемом конфиге и QR всегда заменяется на основной домен из `VPN_DOMAIN`, даже если внутренний контейнер раньше сохранил IP;
- продление миссии, обрыв канала, возврат в строй и заметание следов;
- автоматическое сжигание просроченных доступов;
- радар состояния всех узлов;
- ручная и автоматическая доставка свежих патчей.

Небольшой словарь cicig:

- **нода** — ваш сервер;
- **ключ ушёл в прод** — клиент создан и конфигурация готова;
- **кошачий сейф** — защищённая админ-панель;
- **замести следы** — удалить выбранного клиента;
- **залить патч** — безопасно обновить всю систему;
- **туннель поднят** — VPN-сервис работает.

## Залить свежий патч на всю ноду

Кнопка **«Отправить кота за патчем»** забирает актуальную версию ветки `main` из GitHub, патчит код и конфигурацию, подтягивает новые образы, пересобирает панель и перезапускает весь стек. Кот возвращается сам — будить его по SSH не нужно.

Автоматическое обновление выполняет ту же операцию через заданный интервал. Во время обновления панель может быть недоступна несколько секунд. Файл `.env`, HTTPS-сертификаты, база панели, VPN-ключи и клиенты хранятся отдельно и не удаляются.

Ручное обновление из терминала:

```bash
docker run --rm --name cicig-updater \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/cicig:/opt/cicig \
  docker:cli sh /opt/cicig/scripts/update.sh
```

## Что нужно для поднятия ноды

- Ubuntu 22.04/24.04 или Debian 12;
- публичный IPv4-адрес;
- A-записи основного домена и поддомена `panel`, направленные прямо на сервер;
- свободные TCP-порты 80 и 443;
- свободные UDP-порты 443 и 51820;
- архитектура Linux `amd64` для используемого образа AmneziaWG.

## Команды для оператора

Проверить пульс ноды:

```bash
cd /opt/cicig
docker compose ps
```

Прочитать чёрный ящик:

```bash
cd /opt/cicig
docker compose logs --tail=200
```

Если AmneziaWG перезапускается:

```bash
cd /opt/cicig
docker compose ps awg-easy
docker compose logs --tail=200 awg-easy
test -c /dev/net/tun && echo "TUN/TAP доступен" || echo "TUN/TAP отключён"
uname -m
```

Требуются архитектура `x86_64`/`amd64`, устройство `/dev/net/tun`, возможности `NET_ADMIN` и `SYS_MODULE`. В текущем образе `yokitoki/awg-easy` приложение сохраняет конфигурацию в `/etc/wireguard`, но `wg-quick` ищет её в `/etc/amnezia/amneziawg`. cicig подключает один защищённый volume к обоим путям, поэтому контейнер запускается, а ключи остаются постоянными.

Передёрнуть рубильник всей ноды:

```bash
cd /opt/cicig
docker compose up -d
```

## Разработка

```bash
cp .env.example .env
docker compose config
docker compose up -d --build
```

Не добавляйте `.env`, VPN-ключи и сгенерированные данные в Git. Постоянные данные находятся в Docker volumes.

Панель имеет доступ к `/var/run/docker.sock`, потому что через неё выполняется обновление системы. Пароль панели фактически даёт административные возможности на сервере: используйте уникальный сложный пароль и своевременно устанавливайте обновления.
